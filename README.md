# Hamma Busness

تطبيق ويب ثابت لإدارة المبيعات والمخزون والعملاء والموردين ورأس المال.

## التشغيل

لأفضل نتيجة على المتصفح الخارجي، شغل الملف:

```bat
start-site.bat
```

سيقوم بفتح الموقع عبر `http://127.0.0.1:4174`.

يمكن أيضاً فتح `dist/index.html` مباشرة بعد فك الضغط، لكن لا تفتح الموقع من داخل ملف ZIP.

## الملفات

- `index.html`: واجهات التطبيق.
- `styles.css`: تنسيق الواجهة.
- `app.js`: منطق التطبيق وحفظ البيانات المحلي وربط GitHub Gist.
- `start-site.bat`: تشغيل الموقع محلياً عبر Python HTTP server.

## ملاحظات

- البيانات تحفظ محلياً في متصفح المستخدم عبر `localStorage`.
- يمكن ربط النسخ الاحتياطي السحابي من شاشة الإعدادات باستخدام GitHub Gist.
